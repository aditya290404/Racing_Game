**APEX VELOCITY 3D**
APEX VELOCITY 3D is a browser-based, high-performance racing simulator built with Three.js and native Web Audio. Designed entirely from scratch without external physics engines, it delivers realistic vehicle dynamics, high-speed drifting, and a sleek Apple iOS/visionOS inspired "Liquid Glass" telemetry interface right inside your browser.

✨ Key Features
Advanced Vehicle Dynamics Engine: Modeled with Pacejka-inspired lateral slip friction, weight transfer (pitch/roll suspension behavior), aerodynamic drag, and grass off-track friction penalties.

Pro Drift & Counter-Steer Mechanics: Execute controlled high-angle drifts using the handbrake (Spacebar) or hard cornering, complete with glowing brake rotors, high-angle friction sparks, and dual tire skid marks.

Procedural Web Audio Engine: Dynamic engine RPM frequency synthesis, gear-shift roars, tire squeals, and N2O boost hums generated live via the Web Audio API.

Apple Liquid Glass HUD: A modern translucent UI featuring a live tachometer, gear indicator, Nitro boost gauge, radar minimap, and real-time drift angle & combo multiplier tracking.

AI Opponents & Closed Circuit: Race against autonomous AI drivers around a custom Grand Prix track with particle smoke effects and volumetric lighting.

🎮 Controls
Accelerate / Reverse: W / S (or Up / Down)

Steer Left / Right: A / D (or Left / Right)

Handbrake / Drift: Spacebar

Nitro Boost: Shift
